# Class VIII — Half Yearly Study Calendar

A single-page, self-contained HTML study planner for **The Shriram Millennium School, Noida — Class VIII, 2026–27 Half Yearly exams**. Open the file in any browser — no build step, no server, no dependencies to install.

## Features

- **Exam dates & timings** panel — set/edit your own exam schedule per subject.
- **Progress tracking** — mark each subject/topic as done, with a visual "paper ladder" showing completion at a glance.
- **Difficulty weighting** — flag how hard each subject is for you so the planner can help you prioritize.
- **Auto-generated day-by-day phases** — splits the run-up into a pre-exam prep phase and an exam phase, based on the dates you enter.
- **Light & dark themes** — follows your system preference automatically, with manual override support.
- **Fully offline & private** — all data (exam dates, progress, difficulty) is saved to your browser's `localStorage`. Nothing is uploaded anywhere.

## Usage

1. Open [`Class-VIII-Half-Yearly-Study-Calendar.html`](Class-VIII-Half-Yearly-Study-Calendar.html) in a web browser (double-click it, or drag it into a browser window).
2. Fill in exam dates and timings for each subject in the **Exam dates & timings** panel.
3. Rate subject difficulty in the **Progress** panel to tailor your revision plan.
4. Check off topics as you complete them — your progress is saved automatically in the browser.
